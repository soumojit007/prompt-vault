📖 Quick 3-Step Setup Guide

1 Create or Import Sheet

Create a new Google Sheet or click Download CSV Template above, then import it into Google Drive.

2 Add Your Prompts & Categories

Type your prompts, categories, and tags. You can add brand new categories freely—PromptVault will detect and create them automatically!

3 Share Link & Click Sync

In Google Sheets, click Share > change General Access to "Anyone with the link can view", copy the link, paste it above, and hit Sync Prompts Now.

📋 Supported Google Sheet Columns

Column headers are flexible and case-insensitive. Here is the recommended structure:

Column Header Required? Type / Options Example Value Notes
Title Required Text 30-Sec Cyberpunk Hypercar Chase Matches existing prompts to update or creates new.
Category Optional Text Fantasy & Sci-Fi Any name! Automatically creates category if it doesn't exist yet.
Tier Optional free or premium premium Premium prompts are protected by VIP lock.
Aspect Optional 16:9, 9:16, 1:1 16:9 Aspect ratio tag shown on cards.
Tags Optional Comma-separated Cyberpunk, Neon, 8K Keywords used for search & filter.
Thumbnail Optional Image URL https://images.unsplash.com/... Cover image URL. Fallback image used if left empty.
Description Optional Text High speed cinematic night pursuit Card overview text.
MasterPrompt Required Multiline Text CINEMATIC 8K ACTION ENGINE: [SUBJECT: ...] The full generative prompt copied by users.
Camera Optional Text Anamorphic 35mm, low tracking push-in Camera motion and lens specs.
NegativePrompt Optional Text blurry, cartoon, artifacts, jitter Negative prompt exclusions.
Tools Optional Comma-separated Runway Gen-3, Kling AI Compatible AI video/image engines.
Beats Optional Multiline Text 00-08s: Intro\n08-20s: Climax Pacing timeline breakdown.
